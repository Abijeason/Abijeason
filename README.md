# Hi, I’m Abhishek 👋
### Learning computer science by making things people can use.

I’m a **second-year Computer Science student at the University of Greenwich**. I’m still exploring where I want to specialise, and my projects are how I’m finding out.

So far, that journey has taken me from music discovery websites to portable portfolios—and into the mechanics of a turn-based battle game.

---

### 🧩 Three projects. Different problems.

**“What if sharing your work was as simple as sending one file?”**  
→ **[Portfolio Nest](https://abijeason.github.io/portfolio-nest/)**  
A browser-based builder that brings projects, photos and videos together in one downloadable HTML portfolio. Recipients can open it without an account.

**“How can a music website feel easy to explore?”**  
→ **[Greatest Hits Central]([https://github.com/Abijeason/greatest-hits-central](https://abijeason.github.io/greatest-hits-central/))**  
A responsive music discovery website built with HTML, CSS and JavaScript, with artist pages and interactive navigation.

**“What makes a battle system predictable, testable and fun to build?”**  
→ **[Pokémon-Style-Game](https://github.com/Zain-ux-lab/Pokemon-Style-Game)** · Collaborative project 🚧 **In progress**

A turn-based game we’re still developing together. My merged contributions so far include a Python battle engine, healing and guard mechanics, unit tests, and a CodeQL scanning workflow.

*More features are on the way as we work towards completing the game.*
